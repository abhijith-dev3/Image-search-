# WallpaperApp-Unsplash

A simple, responsive wallpaper app that lets you search and view high-quality images from Unsplash.
Built with HTML, CSS, and JavaScript, this project demonstrates API usage, DOM manipulation, and responsive design.

---

## 🔹 Features

- Search for wallpapers using the Unsplash API
- Display high-quality images with their photographer attribution
- "Show More" button to load additional images
- Responsive design for mobile, tablet, and desktop
- Clean and modern UI

---

> ⚠️ Note: The Access Key included in `script.js` is for learning/demo purposes. For production use, get your own key from [Unsplash Developers](https://unsplash.com/developers).
